## 01 — Brand & Visual Architecture

- **Visual Ratio:** ~60% Charcoal/Near-Black (`#111111` / `#121212`), ~25% Soft White/Neutral Typography & Hairlines (`#F8F8FA`), ~15% Strategic Campaign Photography, ~5–10% Purple Accent (`#4B1FD6`, `#5B1FA6`, `#7C3AED`, `#EBDDFF`).
- **Typography:**
  - Display: `Syne`
  - Body (English): `Plus Jakarta Sans`
  - Body (Thai): `IBM Plex Sans Thai`
  - Telemetry & Editorial Indices: `JetBrains Mono` (`tabular-nums`)
